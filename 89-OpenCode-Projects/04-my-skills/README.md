# 04 - My Skills

Personal collection of OpenCode skills.

## How it works

Skills live in `.opencode/skills/<skill-id>/SKILL.md`. OpenCode discovers them automatically in sessions started from this folder — no configuration needed.

## Skills

| Skill | Purpose |
| --- | --- |
| [`pokemon-info`](.opencode/skills/pokemon-info/SKILL.md) | Live Pokemon data from PokeAPI: types, stats, abilities, evolutions, Pokedex entries |
