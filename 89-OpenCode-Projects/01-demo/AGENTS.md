# AGENTS.md

Static demo website for exploring OpenCode. No build step, no dependencies, no tests.

- Preview: open `index.html` directly in a browser (no dev server needed).
- Styles are inline on `<body>`; move them to a `<style>` block or CSS file if the page grows.
- The README lists Tailwind CSS, but no Tailwind tooling is set up yet — this is plain HTML/CSS.
