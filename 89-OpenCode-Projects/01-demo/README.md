# My First Website

A website used to explore and learn a little about [OpenCode](https://opencode.ai).

## Technologies

- HTML
- CSS
- Tailwind CSS (v4 via browser CDN)
- JavaScript

## How to Run

Open `index.html` directly in a browser. No build step; an internet connection is needed for the Tailwind CDN.
