# Arcade Vault — Gamepad MK-II

Ready-to-use neon gamepad component, extracted from the Arcade Vault portal.

## Files

- **`gamepad.html`** — Standalone page with the gamepad. Supports keyboard (arrows/WASD, Z/J = A, X/K = B) and pointer events (mouse + touch).
- **`gamepad-neon.png`** — Screenshot of the component

## Usage

Open `gamepad.html` directly in any modern browser. To embed it in another project, copy the contents of the `<style>` block and the HTML inside `.page` — it needs no external libraries (only the Google Fonts).
