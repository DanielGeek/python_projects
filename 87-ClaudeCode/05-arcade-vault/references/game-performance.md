# Game performance status

Memory of the `game-performance-booster` subagent (`.claude/agents/game-performance-booster.md`). One row per game the user asked it to check. A game with no row was never requested. The protocol, the budgets and the frame counter snippet live in `references/performance-baseline.md` (SPEC 14).

`Phone` is `n/m` (not measured) until a real phone gives a number; the 50 FPS phone budget is then unverified, not met. No-GPU numbers come from Chrome for Testing with software rasterization and stand in for a weak phone GPU, so they are relative, not a budget.
